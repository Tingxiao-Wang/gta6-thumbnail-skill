# V2.7.2 · 上传本人照片的默认保护规则

**默认行为：不重新生成本人形象，不需要用户额外声明“不要改脸”。**

当用户提供自拍、写真、真人直播/主播照片并确认作为主体时，Skill 要把该照片识别为真实人像，并在资产信息中标注 `asset_kind: real_person_photo`。默认 A/B/C 的每张封面都使用同一张本人原照片的人物像素；可以抠图、裁切、缩放、移动、放到独立生成的背景上，并叠加标题、气氛与图形。不能重新绘制人脸/五官、发型、表情、服饰、身体、姿态，也不能生成相似的替身。

**用户需要主动明确要求**才开放具体改动，例如“把我这张自拍画成动漫角色”或“请把这张照片里的我的发型改短”；只允许完成明确请求的部分，不自动扩展为其他美颜或整个人物重绘。标题增强、设计风格变换和 A/B/C 的多方案要求均**不等于**授权改变本人。

## 真实运行边界

本地 Python 只生成规则和结构化指令，**没有自动识别真人照片、抠图和生图的能力**。豆包/WorkBuddy 等宿主需要对真实图片进行视觉识别，或由用户明确说明它是本人照片，并把图片本身传给图像处理环节。如果该宿主整体重生成画面且无法保证人物像素一致，**不可**把“相似的人”当作“保留本人照片”；应改为单独生成背景、再用真正的非生成式图层/抠图工具合成。缺乏这些能力时如实说明。

## 给集成工具的结构化字段

```json
{
  "uploaded_images": [
    {"id":"me1", "role":"subject", "path":"portrait.jpg", "asset_kind":"real_person_photo"}
  ],
  "person_regeneration_approval": null
}
```

若用户**明确要求**对该照片做指定人物形象再生成，可记录逐图授权（只能摘录用户原话，不能生成授权文案）：

```json
{
  "person_regeneration_approval": {
    "approved": true,
    "asset_ids": ["me1"],
    "allowed_changes": ["anime_stylization"],
    "explicit_user_request": "把我这张照片变成动漫角色"
  }
}
```

审核时检查：1 原人物是否为原照片图层、未重新生成；2 面容发型身形服饰姿态是否未经授权被改变；3 A/B/C 是否复用同一原图；4 原照片能否被宿主真正读取、合成。任何未经授权的形象重绘判定失败。
