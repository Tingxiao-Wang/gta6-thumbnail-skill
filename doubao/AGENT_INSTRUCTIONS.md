# GTA Thumbnail Pro · V2.8 豆包/WorkBuddy 主执行指令

**只使用本文件的最新 V2.8 生成工作流。V2.1–V2.7 的完整旧指令不再打包进本测试版，不可混入同一轮生成提示词。**

1. **先判断图片用途和门禁状态**：未知是否主体/风格参考/两者都要时提一个关键问题；已确认不重复询问。用户选八步定制时继续按每步一个问题推进。
2. **真人照片不自动重绘**：上传的本人真实照片默认原始像素保留，只允许非生成式抠图、裁切、缩放、移动、图层合成与谨慎颜色适配。明确要求修改具体照片形象才允许范围内重绘。不能抠图时说明限制，不用画中画偷换。
3. **先创意、后风格、再文字**：先问“观众第一眼应该通过画面看懂什么”，确定主体关系、场景深度、画面重构和信息装置。仅一行字幕盖在一张背景上，不算通过。
4. **内容匹配 S01–S12**：读取实际 `scripts/style_system_v27.py` 输出中由 `creative_director_v28.py` 定义的 A/B/C 三套独立方案。用户指定风格或确认了参考风格图时保持它；否则自动匹配三套不同创意组织。
5. **标题与整个画面一起设计**：确保用户原文逐字不变，分成前导、视觉主词、悬念/解释三层（有空层可跳过），以空间、字号、材质形成节奏。不编造用户未提供的“全网首发”、评分、媒体角标或剧情事实。
6. **三张真正不同的封面**：A/B/C 的非文字结构（人物、景别、画面关系、空间、信息主次）不同。不得在同一张底图上改三次字幕伪称有三种创意。
7. **去AI味只清理无意义装饰**：不应消灭必要的粗描边、局部视觉引导、版面元素和标题的冲击力。禁止通用固定粉紫调色覆盖用户风格。
8. **交付需真实出图**：如宿主有图像生成/编辑能力，则实际分别完成三种封面；缺少该能力只输出创意方案与完整提示词，不谎称已出图。若无法可靠生成中文，可先制作有明确排版空区的底图，再交给 `tools/thumbnail-editor.html` 添加文字；不要把中间的无字背景称为最终成品。

**画面提示词的唯一来源**：`scripts/compile_reference_handoff.py` 的 `visual_variants[].prompt`，或 `tools/compile_brief.py` 的 `prompt-A/B/C.txt`。**不得额外叠加旧版 `V241_LAYOUTS` 固定标题坐标、老式 Fxx 排版大段和 V2.1 去 AI 味长列表。** 字效配方只提供颜色、字形和材质建议。

**照片处理**：对原始真人图片，不得将“不可重绘”误解为“不可抠图”。有可用非生成式主体分割工具时应形成透明人物 PNG，再与独立背景合成；无法执行时说明工具缺失。不能把原照片当作 prompt 重新生成另一个相似的人。

**质检方法**：根据实际成品目测视觉故事、非文字设计、标题层次、构图空间、内容真实性；必要时与不加载 Skill 的原生成结果做同条件比较。只有看到真实成品才允许评价，不得因生成了设计指令就自称效果已提高。
