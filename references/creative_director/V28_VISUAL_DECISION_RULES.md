# V2.8 视觉决策层｜唯一入口

> 本文只管画面创意决策与提示词优先级，不替代已确定的素材用途问答、真人保护、事实核验、平台尺寸、安全区与编辑器渲染。**宿主实际执行时只应使用此版本生成的 `visual-prompt-A/B/C.txt` 或 `prompt-A/B/C.txt`，不能再次附加 V2.1/V2.2/V2.4 的默认布局、固定字幕或全局去AI味长提示词。**

## 一、决策层级

1. **确认输入**：图片角色已确认、实际图像可访问；用户准确文案及人物原貌锁定。
2. **视觉内容提问**：观众看到封面后的第一反应是什么？是角色关系、值得讨论的观点、真实线索、行动目标还是意外瞬间？
3. **视觉叙事**：用人物大小关系、镜头景别、前中后景、主次图块与真实功能性元素回答上一个问题，不靠一行大字幕承担所有信息。
4. **风格与证据**：S01–S12 作为创作风格语汇；用户明确指定/上传的风格图仍然优先。具体剧情证据、评分、地图、官方消息必须有可靠输入，否则只能明确称为原创概念。
5. **三段文字设计**：准确原文按前导 / 核心词 / 悬念收尾进行无损拆分；有能力可直接生图合成文字，无法准确生成则无字底图加独立文字图层。`无字底图`只是半成品，不能当作完成的封面。
6. **三套概念**：A、B、C 的差异应同时出现在画面主体/故事关系/景别或空间结构上。仅更换文字坐标、字体和滤镜不是三套设计。
7. **真实成品评测**：对照用户不加载 Skill 的同题材原生结果；不能凭编译器生成三份 JSON 就声称提高了设计能力。

## 二、创意原则

- **有设计不等于装饰多**：主体重排、图层空间、信息主次、图与字的穿插才是有效设计；随机箭头、无意义英文、假资讯条是无效内容。
- **标题参与构图，不是事后压在底部**：例如「万字解析：GTA6到底讲了什么故事？」的视觉层级可以是「万字解析」(导语)、「GTA6」(核心主词)、「到底讲了什么故事？」(悬念句)。分层后必须能按原文顺序完整拼回。
- **标题不可被过度去AI味削弱**：保留所选风格有意使用的粗描边、立体字、大小对比、动势，但不要机械套所有效果。
- **真实人物绝不擅自重绘**：如只有原始本人照片，优先非生成式抠图/蒙版+独立背景，绝不能以“原创游戏人物”替代；如果宿主工具不具备此能力，要说清限制，不能用矩形画中画冒充抠图。
- **不编造事实**：无证据的评测数字、游戏剧情、未发布内容、预告片彩蛋均不得伪装成真实截图/新闻。

## 四、失败与降级

- **整图只剩一行普通字幕**：返工整图创意，不是再加一次描边。
- **只有一张底图可用**：最多称为三套字体排版演示；不能称为 A/B/C 三种完整视觉方案。
- **无证据却需要多图拼贴**：使用用户提供的不同素材或原创抽象编辑图形，但不得创造“已确认游戏线索”；没有可用素材时诚实降级。
- **宿主不能抠图**：报告缺少分割/图层能力，不能偷偷把照片处理成画中画。

## 五、评估方法

同题、同输入素材、同模型、同画幅下，对原生模式与 Skill 模式的真实成品进行配对比较；使用 `scripts/visual_benchmark_v28.py` 记录视觉叙事、非文字设计、标题层级、构图纵深、内容真实性五个维度（0–5 分）。该脚本不会读图片，必须由实际看过图的人/视觉模型填写分数。不得把某一次主观评分视为 CTR 提升证据。
